## Key Highlights

- **Dynamic Motion & Physics-Driven UI:** Smooth preloader counter sequence, fluid curtain-style section transitions, and interactive antigravity elements.
- **Interactive Expertise Cards:** Hover-responsive architecture highlighting core competencies across Backend, Frontend, Full-Stack Development, and Data Analytics.
- **Featured Projects Showcase:** Dedicated visual presentations for end-to-end systems including **NexusReserve**, **E-Commerce Demand Forecasting**, and **IncidentFlow**.
- **Infinite Tech Stack Marquee:** Continuous showcase of core tools and frameworks.

## Tech Stack

- **Frontend:** React, TypeScript, Tailwind CSS, Vite
- **Animations & Motion:** Antigravity / Custom Physics & CSS Transitions
- **Featured Project Ecosystems:** Python, Django, PostgreSQL, Redis, Docker, SQL Server, Pandas, Scikit-Learn, Power BI

## Getting Started

To run this project locally:

```bash
# Clone the repository
git clone [https://github.com/AysegullYavuz/aysegul-portfolio.git](https://github.com/AysegullYavuz/aysegul-portfolio.git)

# Navigate to the project directory
cd aysegul-portfolio

# Install dependencies
npm install

# Start the development server
npm run dev
